Build a polished one-page portfolio that presents Adeniyi as an emerging frontend developer, with his engineering background as supporting evidence of transferable skills.

## Experience
- Create a sticky responsive navigation with smooth section links and a mobile menu.
- Build Home, About, Skills, Services, Projects, Experience, Career Journey, Contact, and Footer sections.
- Use a premium near-black/navy design with restrained cyan accents, bold Space Grotesk typography, subtle motion, and responsive layouts tailored for phones through large desktops.
- Use the supplied reference for visual pacing and section composition, while adapting it to the requested dark developer aesthetic.
- Add an illustrated professional portrait treatment and detailed project preview artwork rather than unrelated stock imagery.
- Make contact details actionable; the form will open the visitor's email app with the completed message because no mail service was requested.

- Add unique home-page metadata and verify desktop and mobile rendering after implementation.
